# Security Policy

## Supported Versions

Only the latest release will be supported:
https://github.com/paulte/tampermonkey-tools/releases/latest

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project,
please do not report it through a public GitHub issue, pull request, or
discussion.

Instead, please use GitHub's Private Vulnerability Reporting feature to
submit the vulnerability securely.

When reporting a vulnerability, please provide as much of the following
information as possible:

A description of the vulnerability and its potential impact.
The affected version(s).
Steps to reproduce the issue.
A proof of concept, where appropriate.
Any suggested mitigation or fix, if known.
What to expect

We will acknowledge receipt of a vulnerability report as soon as reasonably
practical and aim to provide an initial assessment within 7 days.

If the vulnerability is confirmed, we will:

Assess its severity and affected versions.
Develop or coordinate an appropriate fix.
Release a security update where necessary.
Publish an appropriate security advisory through GitHub.
Credit the reporter where they have given permission to be acknowledged.

If a report is determined not to be a security vulnerability, we will explain
the reasoning where appropriate.

Please allow reasonable time for a vulnerability to be investigated and fixed
before making details publicly available.

## Security Advisories

Confirmed vulnerabilities may be disclosed through GitHub Security Advisories.
The timing and content of any public disclosure will depend on the severity of
the vulnerability and the availability of a fix.

Thank you for helping to keep this project secure.
